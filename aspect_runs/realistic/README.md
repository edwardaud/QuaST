# The realistic ASPECT case

The ASPECT input cards, the plugin that gives ASPECT the same composite rheology,
and the scripts that read the results back and compare them with a QuaST run.

Running any of this needs the ASPECT image and the plugin built against it. Neither
is part of this repository. The comparison is written up in
[../../docs/dev/VALIDATION.md](../../docs/dev/VALIDATION.md) and summarised in
[../../docs/en/validation.md](../../docs/en/validation.md).

## Cards

| Card | What it is for |
|---|---|
| `realistic.prm` | The base case: 2.5 x 1 box, composite rheology, two phase transitions |
| `realistic_E.prm` | The same case at the production resolution |
| `realistic_E6.prm`, `realistic_E6_long.prm` | Finer wall strips, short and long windows |
| `realistic_ens1.prm` ... `realistic_ens3.prm` | Ensemble members, for the variance estimate |
| `realistic_noav.prm` | Artificial viscosity off, for the sensitivity check |
| `control_nophase.prm`, `control_nolatent.prm` | Controls with one physics ingredient removed |
| `verify100.prm`, `verify7000.prm` | The two verification windows used in the comparison |
| `test.prm`, `test2.prm`, `prodtest.prm` | Short cards used while setting the case up |
| `realistic_E_cont.prm`, `realistic_E_long.prm` | Generated by the `make_*.py` scripts; do not edit by hand |

## Plugin

`realistic_composite.cc` is the material model ASPECT uses: diffusion and
dislocation creep, the yield stress, and the isostress blend. `CMakeLists.txt`
builds it against the ASPECT installation.

## Scripts

| Script | What it does |
|---|---|
| `make_cont.py`, `make_long.py`, `make_ens.py`, `make_noav.py`, `make_e6_long.py` | Write a derived card from the base one |
| `extract_aspect_state.py` | Writes an ASPECT state as an ASCII field for `examples/import_aspect_state.jl` |
| `compare_E.py`, `e6_compare.py`, `e6_long_compare.py`, `same_state_compare.py` | Compare a QuaST run with an ASPECT run, over a window or at one state |
| `long_window.py`, `project_E.py`, `project_e6.py` | Project the series onto the QuaST time axis |
| `nu_bot_check.py`, `av_bl_check.py`, `bl_profile_compare.py` | The bottom-flux gap: its size, the wall profile, the artificial-viscosity sensitivity |
| `phase_check.py`, `vtu_diagnostics.py` | Field-level checks on the phase transitions and the VTU output |
| `av_stats.py`, `ensemble_E.py`, `dt_check.py`, `sd_explore.py`, `check_e6_restore.py` | Ensemble spread, time-step sanity, restart checks |
